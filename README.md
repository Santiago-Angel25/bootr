# Portal de Noticias

Proyecto desarrollado para el parcial de Frontend.

## Tecnologías utilizadas
- HTML
- CSS
- Bootstrap 5

## Descripción
Este proyecto es un portal de noticias que incluye:

- Página principal con tarjetas de noticias
- Página de misión
- Página de visión
- Página de equipo
- Formularios de registro e inicio de sesión
